NETORACLE

Network intelligence and attack forecasting

An offline forecasting prototype for modeling temporal network state, future attack risk, and predicted MITRE ATT&CK stages from prepared network telemetry.

The model reads the six most recent 10-second network-state windows (t-5 … t, 157 features each) and forecasts the next six windows (t+1 … t+6): one whole-horizon attack-risk score, a six-step MITRE-stage trajectory, six predicted future network states, and Gradient × Input feature attribution.

What the model produces

01

Network state

157-feature temporal state representation, built from 10-second network-flow windows.

02

Future risk

Whole-horizon attack-risk score over the forecast window. One score for the whole horizon t+1 … t+6. It is not a six-element per-step series and it is not a calibrated probability.

03

MITRE trajectory

Six-step predicted stage trajectory from a six-class stage head (a reasoned label mapping, not MITRE ground truth).

04

Explainability

Gradient × Input feature attribution: post-hoc attribution of the model output to the observed input features.
