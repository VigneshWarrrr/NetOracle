Attack-risk forecasting
from network-flow windows.

The model reads the six most recent 10-second network-state windows (t-5 … t, 157 features each) and forecasts the next six windows (t+1 … t+6): one whole-horizon attack-risk score, a six-step MITRE-stage trajectory, six predicted future network states, and Gradient × Input feature attribution.

What the model produces

Replay demo — not live detection
  • Attack-risk score — one score for the whole horizon t+1 … t+6. It is not a six-element per-step series and it is not a calibrated probability.
  • MITRE-stage trajectory — a predicted stage for each of the six steps, from a six-class stage head (a reasoned label mapping, not MITRE ground truth).
  • Future-state rollout — six predicted 157-feature network states.
  • Explanation — post-hoc Gradient × Input feature attribution.

The forecast page runs the model on a validated replay window taken from the held-out test split of the Phase 3.5 dataset. This dashboard does not perform live network detection. The first request loads the model and takes about 20 seconds.
